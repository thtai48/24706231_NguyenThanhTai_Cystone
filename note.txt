4. BÀI TẬP CẦN LÀM / ASSIGNMENTS
--------------------------------------------------------------------------------

  w3_1_Data-Wrangling_tiki.ipynb
      Data Wrangling — Tiki e-commerce (2 bộ giày nam / nữ).
      Áp dụng lab/w3_0_Data-Wrangling.ipynb.
      Dataset: tiki_data/vietnamese_tiki_products_men_shoes.csv
               tiki_data/vietnamese_tiki_products_women_shoes.csv
      Nguồn:
        https://www.kaggle.com/datasets/michaelminhpham/vietnamese-tiki-e-commerce-dataset
      Biến mục tiêu gốc: quantity_sold.

      Làm đủ 6 bước trên bộ nam (có dòng mẫu), rồi lặp lại trên bộ nữ:
      1. Missing values
      2. Correct data format
      3. Standardization (VND → nghìn đồng, % giảm giá)
      4. Normalization (x / max)
      5. Binning giá (Low / Medium / High)
      6. Dummy (fulfillment_type)
      Check and save: tiki_men_shoes_clean.csv, tiki_women_shoes_clean.csv

  w3_2_Matplotlib.ipynb
      Data Visualization with Matplotlib (nhà California).
      Áp dụng lab/w3_2_introduction_matplotlib.ipynb
              và lab/w3_4_How-to-Read-Plots.ipynb.
      Dataset: ./data/housing.csv
      Câu hỏi chính: đặc trưng nào liên quan đến gia_nha_trung_vi
                     (median house value)?

      Nội dung:
      1. Import data
      2. Line plot
      3. Scatter plot
      4. Bar plot
      5. Histogram
      6. Subplots
      Điền Question #1–#7 và viết nhận xét (không copy nguyên demo).

  w3_3_Data-Wrangling_student_feedback.ipynb
      Data Wrangling — phản hồi sinh viên (văn bản).
      Áp dụng lab/w3_0_Data-Wrangling.ipynb.
      Dataset: student_feedback_data/synthetic_train.csv
               student_feedback_data/synthetic_val.csv
      Nguồn:
        https://www.kaggle.com/datasets/toreleon/synthetic-vietnamese-students-feedback-corpus

      Làm đủ 6 bước trên train (có dòng mẫu), rồi lặp lại trên validation:
      1. Missing values (câu rỗng → drop; sentiment/topic → mode)
      2. Correct data format (category; n_chars, n_words)
      3. Standardization (sentiment → -1 / 0 / 1)
      4. Normalization (độ dài câu)
      5. Binning Short / Medium / Long
      6. Dummy (topic)
      Check and save: student_feedback_train_clean.csv,
                      student_feedback_val_clean.csv
